# Family Budget Bot

Закрытый Telegram-бот семейного бюджета: принимает фотографии чеков, распределяет позиции по категориям, переводит любые поддерживаемые фиатные валюты в KZT по официальному курсу НБК и ежедневно показывает остатки.

Подробные бизнес-правила и схема компонентов находятся в [ARCHITECTURE.md](ARCHITECTURE.md).

## Возможности

- семейная Telegram-группа с allowlist одного чата и двух пользователей;
- чеки фотографией, image-документом или альбомом: JPEG/JPG, PNG, WEBP, GIF,
  HEIC/HEIF, AVIF, TIFF и BMP;
- OpenAI Responses API с image input и строгим Structured Output;
- позиции на иностранных чеках показываются по-русски, а исходный текст сохраняется для аудита;
- смешанный чек делится между несколькими категориями;
- цены позиций показываются как напечатано, а общая скидка выводится отдельной строкой;
- THB, VND, KZT, RUB и другие ISO 4217 валюты;
- официальный текущий/исторический курс НБК, включая номинал `1000 VND`;
- оригинальная сумма, KZT-эквивалент и влияние на THB-конверт сохраняются отдельно;
- ручные расходы, зарплаты и пополнения целей обычным текстом;
- голосовые расходы с OpenAI transcription и классификацией;
- исправление последнего расхода или позиции чека текстом/голосом;
- цель «Автомобиль» 1 200 000 KZT;
- фонд бордеррана 300 000 KZT с месячным взносом 50 000 KZT;
- ежедневный отчет в 23:00 `Asia/Bangkok`;
- полный отчет по обычной фразе или голосовому запросу вроде «скинь отчёт»;
- PNG-график, защита от дублей, audit trail и восстановление очереди после restart.
- повторная отправка неудачного или отменённого чека перезапускает обработку, а уже
  проведённый чек никогда не списывается второй раз.

## Безопасность

Никогда не сохраняйте реальные секреты в репозитории. Если OpenAI key или Telegram bot token были отправлены в чат, issue, commit или лог, их необходимо немедленно перевыпустить.

В Git разрешено добавлять только [.env.example](.env.example). Реальный `.env` исключен через `.gitignore`.

## Локальный запуск

Требования: Python 3.12+, PostgreSQL 17+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
alembic upgrade head
uvicorn family_bot.main:app --reload --port 8000
```

Production по умолчанию использует long polling. Webhook оставлен как
опциональный режим `TELEGRAM_DELIVERY_MODE=webhook`.

## Первый запуск Telegram

1. Перевыпустите ранее опубликованный bot token через BotFather.
2. В BotFather отключите Group Privacy (`/setprivacy → Disable`).
3. После изменения privacy удалите и снова добавьте бота в семейную группу.
4. Временно установите `SETUP_MODE=true` и `TELEGRAM_OWNER_USER_ID`.
5. Владелец пишет в семейной группе `/setup`.
6. Остальные участники подключаются автоматически при первом сообщении, фото или голосовом.

Если владелец сразу напишет финансовую операцию вместо `/setup`, бот сам привяжет
эту группу и обработает сообщение. Команды допускают обычную пунктуацию: `/setup.` и
`/balance!` тоже распознаются.

## Сообщения

Обычный текст и расшифрованные голосовые всегда сначала классифицирует нейросеть. Она
выбирает между расходом, доходом, пополнением цели, списанием из фонда, исправлением и
нефинансовым сообщением. Регулярные выражения используются только для служебных команд.

```text
такси 180 бат
в 7-Eleven купил Coca-Cola за 35 бат
нет, это было молоко за те же деньги
кафе 500000 донгов
получена зарплата 840000 тенге
отложил 600000 тенге на машину
ноутбук стоит миллион тенге, отложил 300000 тенге
отложил 50000 тенге на бордерран
измени цель MacBook M5 на MacBook M6, новая стоимость 1000000 тенге
```

Новые цели создаются из обычной фразы. Если общая стоимость не названа, бот записывает
взнос и просит указать её следующим сообщением. Все цели ведутся параллельно и показывают
накопленную сумму и остаток.
Явное изменение существующей цели обновляет её название и/или стоимость на месте:
накопленная сумма сохраняется, а новая цель-дубль не создаётся.

После подключения бот показывает постоянное Telegram-меню: `💰 Баланс`, `🧾 Сегодня`,
`🎯 Накопления`, `📊 График`, `💵 Доходы`, `❓ Помощь`. Слеш-команды запоминать не нужно.

Telegram-команды перечисляются латиницей из-за ограничений BotFather:

- `/balance` — полный текущий отчет;
- `/today` — последние расходы;
- `/chart` — PNG-график;
- `/goal` — автомобиль и бордерран;
- `/income` — ожидаемые и полученные зарплаты;
- `/close` — в последний день месяца посчитать фактический свободный
  остаток и перенести его в любую активную цель или оставить резервом;
- `/help` — подсказка;
- `/ids` — идентификаторы только при `SETUP_MODE=true`.

Русские варианты, введенные вручную (`остаток`, `сегодня`, `график`, `цель`), тоже поддерживаются.
Закрытие месяца также срабатывает из текста или голосовой фразы вроде
`всё, месяц закончен`. Бот берёт все фактические поступления, вычитает расходы и уже
сделанные переводы в накопления, а затем показывает кнопки всех активных целей.

Каждый день в 23:00 по часовому поясу семьи бот отправляет итог: траты за день,
потрачено и осталось по каждой категории, общий остаток, доходы и прогресс всех целей.

Если валюты нет у НБК и fallback не настроен, владелец может зафиксировать ручной курс на текущую дату:

```text
/rate XXX курс_в_тенге номинал
```

Пример: если 100 единиц валюты стоят 2500 KZT, команда будет `/rate XXX 2500 100`.

## Coolify

Deployment в этой версии не выполняется автоматически. Для ручного подключения:

1. Создайте PostgreSQL resource и приложение из GitHub-репозитория.
2. Выберите build из `Dockerfile`, expose port `8000`.
3. Подключите постоянный volume к `/data/receipts`.
4. Установите `TELEGRAM_DELIVERY_MODE=polling`; HTTPS-домен нужен для healthcheck,
   но не для доставки Telegram.
5. Добавьте все значения из `.env.example` через Coolify Environment Variables.
6. Используйте внутренний PostgreSQL URL вида `postgresql+asyncpg://...`.
7. Установите healthcheck path `/health/ready`.
8. Оставьте одну replica: scheduler защищен на уровне записей БД, но MVP рассчитан на один процесс.
9. После запуска проверьте `/health/live`, `/health/ready`, лог `Telegram long polling
   started`, `/start`, тестовый расход и вечерний отчет.

Миграции Alembic выполняются контейнером перед запуском Uvicorn. Секреты должны находиться только в Coolify Environment Variables.
